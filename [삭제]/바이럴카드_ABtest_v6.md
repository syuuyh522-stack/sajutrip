# 바이럴 카드 A/B 설계 — K-Saju Compass (v6 서브)

> 작성일: 2026-07-15 | 상위: [[초기트래픽_GTM_v6]] | 원칙: 지금은 트래픽 부족 → 2단계(질적 → 진짜 A/B). 공유율은 K를 곱셈으로 키운다.

## 1. 지표 & 계측 (없으면 실험 불가)

- **1차 지표**: 공유율 = 공유 실행 / 결과 조회
- **북극성**: K = (유저당 공유수) × (공유당 유입) × (유입당 활성)
- **2차**: 공유 카드 CTR, 완료율(입력→결과)
- **가드레일**: 신고/불만율(미신 백래시), 완료율 하락, 부정 반응
- **이벤트 파이프**: result_view → share_click → share_completed → shared_visit → new_result_view
- **필수 인프라**: 카드마다 **고유 딥링크(UTM)** → 구축 S3/S4 태스크

## 2. 2단계 로드맵 (현실 인정)

- **Phase 0 (베타·시드, 트래픽≈0, 통계 아님)**: 타깃 8~12명에게 카드 3종 → "어느 걸 공유하겠나, 왜" (UT·팬 커뮤니티 DM) + painted-door 눈대중 → 강한 기본값 선택
- **Phase 1 (변형당 ~2–3k 결과조회)**: 진짜 A/B. baseline 공유율 ~15% 가정, +20% 상대 상승 감지 → 변형당 ~2,000–3,000. 초기엔 **대담한 차이**를 테스트하면 +50%도 노려 변형당 ~1k로 절약.

## 4. 1순위 실험 — 헤드라인 프레이밍

**Because** 타깃이 팬덤 정체성 콘텐츠에 강하게 반응, **we believe** 헤드라인을 "My Saju Twin: [아이돌]"로 바꾸면 **will cause** 공유율 +20%p대 상승 **for** 방한 예정 글로벌 K팬. **We'll know** 공유율로 판정.

- A(control): "My Korea Element: 水 → 강원"
- B(challenger): "My Saju Twin: [아이돌] · 우리 같은 사주 여행지는?"
- C 보류(2변형으로 트래픽 절약): "97%는 서울, 나는 강원"(다음 라운드)
- 1차 지표: 공유율 / 가드레일: 신고율·완료율
- 결정 규칙: 표본 도달 + p<0.05 + 가드레일 악화 없음 → 승자 채택. 무의차면 더 대담한 변형.

## 5. 운영 규율

- 한 실험 = 한 변수. 가설·1차지표·표본 **사전 등록**. 중간에 훔쳐보고 멈추기 금지.
- 승자는 **플레이북에 패턴 기록** → 다른 표면 재사용.
- 속도(현 단계): 월 1~2개. 광고·발행 액션엔 사람 체크포인트.
