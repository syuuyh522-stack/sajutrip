## 아키텍처 · 데이터 흐름

`입력(생년월일시·언어)` → `사주 엔진(음양력→만세력 4주→오행·용신)` → `매핑·매칭(오행→권역 테이블 + 스타 명식 DB)` → `KTO 프록시(서버리스, 키 은닉)` → `결과(치유 코스 + 스타 + OG 공유카드)`

**스택**: Next.js(웹 우선) · 서버리스 API(TourAPI 키 은닉) · 사주계산(lunar-javascript/KASI 음양력) · 정적 스타 명식 JSON · i18n 3언어 · OG/canvas 이미지 · 정적+서버리스 배포
