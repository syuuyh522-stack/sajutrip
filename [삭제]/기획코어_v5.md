# K-Saju Compass — 기획 코어 (제품 토대)

> 작성일: 2026-07-15 | 나머지 파트(전략·사주·K-Star·구축)의 근거가 되는 제품 토대.
> 확정: 타깃 = **방한 예정 글로벌 K팬** / 가치 = 하나의 여정, **세 레이어(유입→결정→전환)**
> 팀: 나(리서치) · 동료(PO) · Claude(구현)

## 문제 정의 (과제 3, 우리 언어로)

- **공고 과제 3**: K-콘텐츠·아티스트 관광 인프라의 수도권 편중 + 글로벌 팬덤의 지방 방문·탐방 편의성 미흡
- **진짜 문제(우리 진단)**:
  - 방한 예정 K팬은 갈 마음은 있으나 **수도권 밖 '어디'를 정할 근거가 없다**
  - 지방을 **"나와 상관있는 곳"으로 느낄 개인적 연결고리가 없다** → 서울에 머문다
  - **가설**: 개인화된 "너만의 이유"를 주면 지방 방문 의사결정이 열린다

## 타깃 페르소나 — 글로벌 K팬 "제인"

- 24세, LA/방콕/파리, K-pop·드라마 팬, 방한 계획 중, FIT, TikTok·샤오홍슈
- 서울 일정은 정했는데 "그다음 어디?"가 막막 — 지방은 정보·엄두 부족
- 사주 = 이색 K-경험으로 호기심(한국식 MBTI), 공유 욕구 큼
- 다국어 앱 익숙, 결제력 중상, 성지·로컬 경험 갈망
- **Non-target**: 단체 패키지 관광객, 사주 강한 거부층

## 가치 제안 — 하나의 여정, 세 레이어

"균형"은 셋을 따로 파는 게 아니라 한 여정의 퍼널을 세 레이어가 나눠 맡는 것.

| 레이어 | 역할 | 내용 |
|------|------|------|
| 재미·바이럴 | 유입(Acquisition) | 사주 트윈·궁합 K-Star + 공유카드 → 팬덤 확산으로 **데려온다** |
| 발견(코어) | 결정(Core job) | 사주로 "나에게 맞는 진짜 한국(지방)" 처방 → 여행 결정 근거를 준다 |
| 웰니스·예약 | 전환(Monetize) | 용신 치유 코스 + KTO + 예약 딥링크 → 방문·결제로 **전환한다** |

## 과제 적합성 — 인과 사슬 (심사 필수 준수사항 ①)

과제(수도권 편중·팬덤 지방방문 불편) → 근본원인(결정 근거·개인 연결고리 부재) → 우리 개입(사주 개인화 처방 + 스타 고향 연결) → 지방 방문 의사결정↑ + KTO로 실체화 → **과제 해소 = 인바운드 지방 분산**

> 즉 사주는 재미가 아니라 **지방 분산을 일으키는 개인화 트리거**.

## 핵심 시나리오 (제인)

1. 제인(24, LA, aespa 팬), 10월 첫 방한 — 서울 4일은 정했는데 "그다음?"
2. TikTok에서 친구의 "My Korea Element" 공유카드 → 진입
3. 생일 입력(시간 모름) → "水 부족 → 강원" + "사주 트윈·궁합 스타의 고향: 광주"
4. 강원 2박3일 치유 코스 + 광주 성지 코스(KTO·다국어)
5. 숙소 예약 딥링크 + 공유카드로 친구 초대
6. 결과: 서울-only였던 여정이 **강원·광주로 확장 = 지방 분산**
