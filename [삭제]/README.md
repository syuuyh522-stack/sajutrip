# 한국 관광 콘텐츠랩 — 2026 관광데이터 활용 공모전 (②-2 웹·앱 구현 부문)

> 생성일: 2026-07-15 | 상태: 탐색 중 (과제 선정 전)
> ⚠️ **접수 마감: 2026. 7. 21.(화) 16:00 — D-6 (오늘 7/15 기준)**

## 왜 지금 이 주제인가?

_트리거: 한국관광공사(KTO) "한국관광콘텐츠랩"의 2026 관광데이터 활용 공모전 참가 검토. 지정과제 10개 중 1개를 골라 KTO OpenAPI를 필수 활용한 관광 서비스를 개발하는 공모전. 슬로건은 "데이터 가치를 넘어, 서비스로 실현하다: 관광데이터 스케일 UP". 여기어때 리서치 관점의 여행 콘텐츠·데이터 인사이트를 실제 서비스 컨셉으로 검증할 기회._

### 필수 준수사항 (필독)

1. **과제 부합 기획** — 선택한 지정과제의 해결과제를 해소하는 방향으로 서비스 기획
2. **KTO OpenAPI 필수 활용** — 최종 완성 서비스 내 필수. 그 외 외부 API는 자유롭게 추가 가능
3. **중복 출품 불가** — ① 웹·앱 개발 부문과 동시 출품 불가 / ②-1 프롬프톤 제출작과 동일 결과물 제출 불가
